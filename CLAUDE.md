# Instrucciones para Claude Code

Lee y aplica primero [`AGENTS.md`](AGENTS.md); es la fuente canónica de reglas del
repositorio. Usa [`README.md`](README.md) para comprender la estructura y los
comandos, y [`CONTRIBUTING.md`](CONTRIBUTING.md) para el flujo de entrega.

Puntos críticos: edita los `.qmd`, no los HTML generados; conserva los cambios del
usuario; compila la presentación afectada; y revisa visualmente el resultado. Si
este archivo difiere de `AGENTS.md`, prevalece `AGENTS.md`.
